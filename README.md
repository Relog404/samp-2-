## ⚡ ЗАПУСК В ОДНУ КНОПКУ (ДВА СПОСОБА)

### 🥇 Способ 1: Открыть готовый файл места (САМЫЙ БЫСТРЫЙ!)
1. Запустите **Roblox Studio**.
2. В верхнем меню выберите **File → Open from File...** (или нажмите `Ctrl + O`).
3. Выберите файл **`SolsRNG_Game.rbxlx`** из этой папки.
4. Нажмите зеленую кнопку **PLAY** (или клавишу **F5**).
5. **Всё сразу работает!** Платформа, солнечное утро, рулетка CS2, звуки, роллы, эффекты аур, инвентарь и крафт активны!

---

### 🥈 Способ 2: Установщик в один клик (OneClick_Installer.lua)
Если у вас уже открыт пустой Baseplate или любой ваш плейс:
1. В Roblox Studio откройте командную строку: вкладка **View → Command Bar** (внизу экрана).
2. Скопируйте всё содержимое файла **`OneClick_Installer.lua`**.
3. Вставьте в командную строку и нажмите **Enter**.
*(Либо создайте обычный Script в ServerScriptService, вставьте туда код и нажмите Play)*.
4. Скрипт мгновенно создаст всю структуру игры, GUI, модули и платформу. Нажмите **F5 (Play)**!

## 🎮 КЛЮЧЕВЫЕ ФИЧИ И ОБНОВЛЕНИЯ

### 1. 🎰 Динамичный Прокрут Ауры (CS2 Case Opening Roulette)
- При нажатии на кнопку **«ROLL»** на экране появляется горизонтальная барабанная рулетка в стиле кейсов **CS2 / CS:GO**!
- Лента из 44 карточек аур пролетает слева направо с огромной скоростью.
- При прохождении каждой карточки через золотую стрелку-указатель раздается реалистичный четкий щелчок (**«тик-тик-тик»**).
- Лента плавно и реалистично замедляется (по кривой инерции `Quart.Out`), останавливая победную ауру ровно по центру золотой стрелки!
- При остановке стрелка вспыхивает, срабатывает эффект сотрясения экрана и вылетает фанфара/звук соответствующего тира.

### 2. 💰 Понятные Кнопки Экипировки и Продажи
- **Сразу после прокрута рулетки в карточке выпавшей ауры:**
  - **[ ⚔️ ЭКИПИРОВАТЬ СЕЙЧАС ]** — большая зеленая кнопка, моментально надевает ауру на персонажа.
  - **[ 💰 ПРОДАТЬ (+X МОНЕТ) ]** — крупная золотая кнопка с четкой суммой монет (например, `💰 ПРОДАТЬ (+2,000)`). Можно сразу слить ненужную ауру и получить монеты!
  - **[ 🎒 В ИНВЕНТАРЬ ]** — сохранить ауру в хранилище.
- **В окне Инвентаря:**
  - При выборе любой ауры справа отображаются две гигантские удобные кнопки:
    - **[ ⚔️ ЭКИПИРОВАТЬ ]** / **[ ✕ СНЯТЬ АУРУ ]**
    - **[ 💰 ПРОДАТЬ (+X МОНЕТ) ]** с указанием точной суммы монет.

### 3. ☀️ Солнечное Утро вместо Ночи
- Время суток выставлено на **08:00 утра**: яркий, сочный, приятный утренний солнечный свет.
- Эффект **SunRays** (объемные солнечные лучи сквозь горизонт).
- Чистая голубая атмосфера, яркие тени и светлая кварцевая платформа со светящимся неоновым контуром.

### 4. ✨ Сверхплотные и Мощные Эффекты Аур (7 Слоев)
- **Плотность частиц увеличена в 4 раза** (рейты 60–140 частиц/сек).
- **Магические рунические кольца на полу:** двойные концентрические вращающиеся диски и ударные волны под ногами.
- **Восходящее объемное пламя:** плотно окутывает ноги, торс и голову персонажа.
- **Орбитальные искры и метеоры:** постоянно кружат вокруг тела.
- **Нимбы и короны над головой:** вращающиеся кольца света для святых и редких аур.
- **Божественные крылья света:** раскрываются за спиной для высших тиров (Archangel, Solar, Godly).
- **Вертикальные световые столбы:** мощные лазерные лучи в небо для Legendary+.
- **LightEmission = 1.0:** эффекты ослепительно ярко горят даже при прямом солнечном свете!
