# 🎲 Sol's RNG — Полная Готовая Игра для Roblox Studio

> **Мега-трендовый жанр в Roblox!** Полнофункциональный аналог **Sol's RNG**, созданный «под ключ»: красивейший современный GUI, процедурные визуальные эффекты аур (частицы, лучи, подсветка, свет), инвентарь, алхимический крафт, авто-ролл, система удачи, лидерборд и монетизация.

## ⚡ ЗАПУСК В ОДНУ КНОПКУ (ДВА СПОСОБА)

### 🥇 Способ 1: Открыть готовый файл места (САМЫЙ БЫСТРЫЙ!)
1. Запустите **Roblox Studio**.
2. В верхнем меню выберите **File → Open from File...** (или нажмите `Ctrl + O`).
3. Выберите файл **`SolsRNG_Game.rbxlx`** из этой папки.
4. Нажмите зеленую кнопку **PLAY** (или клавишу **F5**).
5. **Всё сразу работает!** Платформа, GUI, звуки, роллы, эффекты аур, инвентарь и крафт активны!

---

### 🥈 Способ 2: Установщик в один клик (OneClick_Installer.lua)
Если у вас уже открыт пустой Baseplate или любой ваш плейс:
1. В Roblox Studio откройте командную строку: вкладка **View → Command Bar** (внизу экрана).
2. Скопируйте всё содержимое файла **`OneClick_Installer.lua`**.
3. Вставьте в командную строку и нажмите **Enter**.
*(Либо создайте обычный Script в ServerScriptService, вставьте туда код и нажмите Play)*.
4. Скрипт мгновенно создаст всю структуру игры, GUI, модули и платформу. Нажмите **F5 (Play)**!

### 1. 🎲 Система Роллов (Core RNG Engine)
- Большая анимированная кнопка **«ROLL»** с плавной физикой нажатия и звуками вращения.
- **⚡ Auto Roll (Авто-ролл)**: автоматическое вращение в фоне пока игрок исследует мир или общается в чате.
- **⏩ Fast Roll (Быстрый ролл)**: моментальный результат для хардкорных игроков без долгой катсцены.
- Динамический расчёт шансов с учётом всех множителей удачи (x2 Luck, VIP, зелья, экипировка).
- Полноэкранная катсцена раскрытия карты ауры с эпическими звуками по тирам (Common, Rare, Legendary, Mythic, Godly).
- **Глобальные серверные оповещения**: при выпадении ауры 1 к 10,000+ по всему серверу вылетает золотой праздничный баннер!

### 3. ✨ Процедурные Визуальные Эффекты (100% Кодом)
- **ParticleEmitter**: генерация частиц разной формы, скорости, ускорения и светоизлучения (LightEmission = 0.9+).
- **Highlight**: неоновое свечение и контур вокруг аватара в цвет ауры.
- **PointLight**: динамический источник света, освещающий персонажа и землю.
- **Vertical Pillar Beam**: восходящий луч небесного света для Легендарных и Мифических аур.
- **Overhead BillboardGui**: парящий бейдж над головой игрока с именем ауры, шансом и VIP-статусом.

### 4. 🎒 Инвентарь и Хранилище
- Сетка карточек аур со счетчиком дубликатов (`x2`, `x5`).
- Индикатор текущего количества слотов (например, `14 / 20 слотов`).
- Действия: **Equip (Надеть)** / **Unequip (Снять)** / **Scrap (Разобрать на монеты)**.
- **Фильтр авто-удаления (Auto-Delete)**: настройка автоматического распыления Common, Uncommon или Rare аур прямо во время ролла, чтобы не засорять инвентарь!

## ⚙️ НАСТРОЙКА И КАСТОМИЗАЦИЯ

### Как изменить GamePass ID для публикации
Откройте файл `src/ReplicatedStorage/Modules/AuraConfig.lua` (или объект `AuraConfig` в ReplicatedStorage в Studio) и укажите ваши реальные ID геймпассов из Create Dashboard:
```lua
AuraConfig.Settings.GamepassIds = {
    X2Luck = 12345678,       -- ID геймпасса x2 Luck
    AutoRoll = 12345679,     -- ID геймпасса Auto Roll
    ExtraStorage = 12345680, -- ID геймпасса Extra Storage
    VIP = 12345681,          -- ID геймпасса VIP
}
```

### Как добавить новую ауру
В `AuraConfig.Auras` просто добавьте новую запись:
```lua
Phoenix = {
    Id = "Phoenix",
    Name = "Phoenix",
    Rarity = 75000, -- 1 к 75,000
    Tier = "Mythic",
    Color = Color3.fromRGB(255, 100, 20),
    Description = "Бессмертное огненное оперение возрождающегося феникса.",
    Cutscene = AuraConfig.CutsceneTier.Mythic,
    ParticleColor = Color3.fromRGB(255, 120, 30),
    ParticleShape = "Flame",
}
```
Игра автоматически включит её в роллы, интерфейс инвентаря и серверные оповещения!
