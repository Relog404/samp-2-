## ⚡ ЗАПУСК В ОДНУ КНОПКУ (ДВА СПОСОБА)

### 🥇 Способ 1: Открыть готовый файл места (САМЫЙ БЫСТРЫЙ!)
1. Запустите **Roblox Studio**.
2. В верхнем меню выберите **File → Open from File...** (или нажмите `Ctrl + O`).
3. Выберите файл **`SolsRNG_Game.rbxlx`** из этой папки.
4. Нажмите зеленую кнопку **PLAY** (или клавишу **F5**).
5. **Всё сразу работает!** Платформа, солнечное утро, рулетка CS2, колесо апгрейдера, PvP дуэли, инвентарь и кузница активны!

---

### 🥈 Способ 2: Установщик в один клик (OneClick_Installer.lua)
Если у вас уже открыт пустой Baseplate или любой ваш плейс:
1. В Roblox Studio откройте командную строку: вкладка **View → Command Bar** (внизу экрана).
2. Скопируйте всё содержимое файла **`OneClick_Installer.lua`**.
3. Вставьте в командную строку и нажмите **Enter**.
4. Скрипт мгновенно создаст всю структуру игры, GUI, модули и платформу. Нажмите **F5 (Play)**!

## 🎰 АПГРЕЙДЕР АУР (КОЛЕСО С ЗОНОЙ ВЫИГРЫША)

В левом док-меню нажмите кнопку с иконкой колеса:
1. **Блок 1 (Слева — Ваша Аура):**
   - Выберите любую ауру из инвентаря для ставки. В карточке превью отобразится эмблема и сумма гарантированного возврата монетами при неудаче.
2. **Блок 2 (Справа — Целевая Аура):**
   - Выберите любую желаемую ауру из каталога — система сама рассчитает честный шанс на победу.
3. **Центр — Барабан со стрелкой и сектором:**
   - **Зеленая зона победы** наглядно показывает дугу выигрыша!
   - Пресеты: `[ 75% ]`, `[ 50% ]`, `[ 30% ]`, `[ 2X ]`, `[ 5X ]`, `[ 10X ]`.
   - Кнопки `[ -5% ]` и `[ +5% ]`, а также поле ввода своего шанса (от 1.0% до 85.0%).
   - Режим: **`[ РЕЖИМ: АРКАДНЫЙ (3.2С) ]`** (по умолчанию) либо **`[ РЕЖИМ: БЫСТРЫЙ (0.6С) ]`**.
4. Нажмите **`[ АПГРЕЙДИТЬ АУРУ ]`**:
   - Стрелка вращается и останавливается на выпавшем градусе.
   - Попадание в зеленую зону = мгновенный выигрыш целевой ауры и денежный приз!
