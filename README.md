## ⚡ ЗАПУСК В ОДНУ КНОПКУ (ДВА СПОСОБА)

### 🥇 Способ 1: Открыть готовый файл места (САМЫЙ БЫСТРЫЙ!)
1. Запустите **Roblox Studio**.
2. В верхнем меню выберите **File → Open from File...** (или нажмите `Ctrl + O`).
3. Выберите файл **`SolsRNG_Game.rbxlx`** из этой папки.
4. Нажмите зеленую кнопку **PLAY** (или клавишу **F5**).
5. **Всё сразу работает!** Платформа, солнечное утро, рулетка CS2, батлы, апгрейдер, инвентарь и крафт активны!

---

### 🥈 Способ 2: Установщик в один клик (OneClick_Installer.lua)
Если у вас уже открыт пустой Baseplate или любой ваш плейс:
1. В Roblox Studio откройте командную строку: вкладка **View → Command Bar** (внизу экрана).
2. Скопируйте всё содержимое файла **`OneClick_Installer.lua`**.
3. Вставьте в командную строку и нажмите **Enter**.
*(Либо создайте обычный Script в ServerScriptService, вставьте туда код и нажмите Play)*.
4. Скрипт мгновенно создаст всю структуру игры, GUI, модули и платформу. Нажмите **F5 (Play)**!

## ⚔️ PVP БАТЛЫ МЕЖДУ ИГРОКАМИ (ДУЭЛИ АУР)

В левом док-меню появилась кнопка **`⚔️ [АРЕНА БАТЛОВ]`**:
1. Открывает список игроков на сервере — нажмите **`[ ⚔️ ВЫЗВАТЬ НА БОЙ ]`**.
2. У противника появляется стильный баннер вызова с кнопками `ПРИНЯТЬ` или `ОТКЛОНИТЬ`.
3. При согласии активируется **Боевой Интерфейс (Combat HUD)**:
   - Вверху экрана: полосы здоровья `ВЫ: 1000 HP` и `ВРАГ: 1000 HP` (максимальное здоровье зависит от боевой мощи надетой ауры!).
   - Внизу экрана: **3 уникальных боевых приема**:
     - **`[1] ⚔️ УДАР АУРЫ`** (кулдаун 1.2с) — стремительный лазерный луч-слэш в противника.
     - **`[2] 💥 ВЗРЫВ СТИХИИ`** (кулдаун 3.5с) — мощная ударная волна, вырывающаяся из-под ног врага.
     - **`[3] ☄️ УЛЬТИМЕЙТ`** (кулдаун 7.0с) — сокрушительный небесный лазер с сотрясением экрана и шансом критического урона (`💥 CRIT! -1,200`)!
4. Над головами персонажей вылетают динамичные всплывающие цифры урона.
5. Победитель дуэли получает **+5,000 монет** и победный фанфарный триумф!

## 🎰 АПГРЕЙДЕР АУР (РИСК-МАШИНА / UPGRADER)

В левом док-меню появилась кнопка **`🎰 [АПГРЕЙДЕР АУР]`**:
1. Поместите ауру из сумки в слот апгрейдера.
2. Выберите режим риска:
   - **Фиксированные шансы:**
     - **75% ШАНС** → прыжок на **+1 тир** вперед.
     - **50% ШАНС** → прыжок на **+2 тира** вперед.
     - **30% ШАНС** → прыжок на **+4 тира** вперед!
   - **Мультипликаторы выигрыша:**
     - **2x МНОЖИТЕЛЬ** (Шанс ~48%) → +2 тира.
     - **5x МНОЖИТЕЛЬ** (Шанс ~19%) → +5 тиров!
     - **10x МНОЖИТЕЛЬ** (Шанс ~9%) → сумасшедший прыжок на **+8 тиров** сразу в Mythic/Godly и куча монет!
3. Нажмите **`[ 🎰 АПГРЕЙДИТЬ / РИСКНУТЬ ]`**:
   - Раздаются вращающиеся щелчки барабана.
   - При успехе: салют, звук победы и выбитая редкая аура сразу падает в инвентарь!
   - При неудаче: аура сгорает с выплатой утешительных монет.
