## ⚡ ЗАПУСК В ОДНУ КНОПКУ (ДВА СПОСОБА)

### 🥇 Способ 1: Открыть готовый файл места (САМЫЙ БЫСТРЫЙ!)
1. Запустите **Roblox Studio**.
2. В верхнем меню выберите **File → Open from File...** (или нажмите `Ctrl + O`).
3. Выберите файл **`SolsRNG_Game.rbxlx`** из этой папки.
4. Нажмите зеленую кнопку **PLAY** (или клавишу **F5**).
5. **Всё сразу работает!** Платформа, солнечное утро, рулетка CS2, донат-панели, звуки, роллы, эффекты аур, инвентарь и крафт активны!

---

### 🥈 Способ 2: Установщик в один клик (OneClick_Installer.lua)
Если у вас уже открыт пустой Baseplate или любой ваш плейс:
1. В Roblox Studio откройте командную строку: вкладка **View → Command Bar** (внизу экрана).
2. Скопируйте всё содержимое файла **`OneClick_Installer.lua`**.
3. Вставьте в командную строку и нажмите **Enter**.
*(Либо создайте обычный Script в ServerScriptService, вставьте туда код и нажмите Play)*.
4. Скрипт мгновенно создаст всю структуру игры, GUI, модули и платформу. Нажмите **F5 (Play)**!

В игру внедрена многоуровневая система монетизации, как в топ-играх Roblox (Pet Sim 99, Sol's RNG, Blade Ball):

  - **Набор Новичка:** `x2 Luck + VIP-статус + 25,000 Монет + Мега-Зелье x5` всего за R$ 149!

### 2. ⚡ Быстрая плавающая донат-панель справа:
- `💎 [ДОНАТ]` — мгновенное открытие полного супермаркета доната.
- `🍀 [x2 LUCK]` — удвоенная удача навсегда.

- `🪙 [+50K МОНЕТ]` — мгновенный мешок золота.

### 3. 🛍️ Полный 4-секционный Магазин Доната:
- **Геймпасы навсегда:** x2 Luck, x3 Luck Overload, Auto Roll, Хранилище +50 слотов, VIP Supporter, Fast Roll Instant.

- **Мгновенный выбив:** Гарантированная Легендарная Аура (1/1000+) и Гарантированная Мифическая Аура (1/10,000+).

## 🔊 МЯГКИЕ И КОМФОРТНЫЕ ЗВУКИ

- Убраны все резкие и неприятные звуки!
- В CS2-рулетке используется **тихий, мягкий тактильный механический щелчок** (громкость 0.15), который не давит на уши даже при частых прокрутах.
- Монеты издают легкий приятный звон.
- В окне **Настроек (⚙️)** добавлена кнопка **`[ 🔊 Звуки Игры: ВКЛ / ВЫКЛ ]`** для моментального отключения аудио в один клик.

## 🎰 ДИНАМИЧНЫЙ ПРОКРУТ АУРЫ (CS2 CASE OPENING)

- Горизонтальный барабан из 44 карточек пролетает слева направо с огромной скоростью.
- Золотая центральная стрелка-указатель фиксирует карточки.
- Реалистичное замедление по кривой инерции `Quart.Out`.
- При выпадении карточки:
  - **`[ ⚔️ ЭКИПИРОВАТЬ СЕЙЧАС ]`** — моментально надеть ауру на персонажа.
  - **`[ 💰 ПРОДАТЬ (+X МОНЕТ) ]`** — сразу слить ненужную ауру за монеты (от 5 до 100,000 монет)!
  - **`[ 🎒 В ИНВЕНТАРЬ ]`** — убрать в инвентарь.
